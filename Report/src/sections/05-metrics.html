05 Performance metrics

Every metric is reported gross and net. Risk-free rate is taken as zero throughout: for a dollar-neutral book the long leg is funded by the short proceeds, so the return series is already an excess return. That does mean these Sharpes are not directly comparable with a long-only strategy's.
