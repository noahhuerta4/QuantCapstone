08 Validation

A backtest is a claim about the future made from the past, and the ways it lies are well catalogued. Five controls run against this one, and the headline number quoted throughout is the walk-forward result — every tunable parameter is re-selected on each fold's training window, so nothing is chosen with hindsight.

Every configuration examined is counted. The Deflated Sharpe Ratio discounts a result for the number of things tried, and it only works if the count is honest. All 443 configurations touched across the project — including exploratory sweeps and every rejected candidate — are fed in, because a parameter chosen by looking at results is a trial whether or not it ran inside the reported script. The count lives in a tracked ledger on disk rather than in anyone's memory: a remembered trial count only ever drifts downward, in exactly the direction that flatters the result.

Engine verification

Two checks run against the backtester itself, independent of any strategy result. With no-trade bands disabled the engine fully rebalances each day, so its gross return must equal a one-line vectorized expression that shares no code with it; they agree to 1×10⁻¹⁷. And shifting the weights a day in either direction must move the result violently — a backtest that scores the same whether it trades on yesterday's, today's or tomorrow's signal is not using the timing it claims.
