13 Reproducing this

The project is a Python package with 262 tests covering the signal, the neutralization algebra, the cost accounting and the point-in-time discipline. A synthetic data generator with deliberately planted effects lets the entire suite run offline and deterministically, and doubles as ground truth: if the pipeline cannot recover a known signal there, the bug is ours rather than the market's.

Every number in this document regenerates from the repository. The headline comes from quant-capstone run; every side study — liquidity deciles, sleeve surveys, the transfer-coefficient variants, the Phase 2 directions, the intraday diagnostic — is a module in quant_capstone/studies that pins the configuration it was originally run under. Their tables are committed under results/studies, and --check regenerates them all and diffs the result against what is committed. The cached market data is pinned too: results/data_manifest.json records the hash of every input file, so a re-download that moves the numbers is caught before anyone starts debugging the model.

CommandWhat it does
uv syncCreate the environment and install dependencies
uv run pytest262 tests, about 20 seconds, no network needed
uv run quant-capstone run --source syntheticFull pipeline offline against planted effects
uv run quant-capstone runThe headline study on real data; downloads and caches on first use
uv run quant-capstone study allRegenerate every side study and every figure in this document
uv run quant-capstone study --checkRegenerate the study tables and diff them against the committed ones
uv run quant-capstone bookAssemble this document from Report/src
uv run quant-capstone crosscheckVerify the engine against independent calculations

Built with numpy, pandas, scikit-learn and statsmodels. Price data from yfinance; fundamentals from the SEC XBRL API; hourly bars from Interactive Brokers via ibapi. All figures generated from the final configuration by quant-capstone study figures.
